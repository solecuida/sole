# Lista de verificación técnica 6.2: evidencia

Fuente: sección 6.2 del brief (`PROTOTIPO-Brief-Fable.md`). Esta tabla dice, punto por punto, dónde se comprueba cada requisito en el repositorio.

**Cómo leerla.** `Cumple` significa que existe una prueba, una migración o una configuración en el repositorio que lo respalda; la ruta está en la columna `Evidencia`. `Lista de lanzamiento` significa que solo se puede comprobar con el sistema desplegado, o que depende de algo que todavía no se construye; la evidencia dice qué falta. Si un punto tiene una parte cumplida y otra pendiente, queda en `Lista de lanzamiento` y la evidencia describe las dos.

Esto es cumplimiento verificable, no una certificación. Se revisa de nuevo antes del lanzamiento (fase 5).
